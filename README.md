# BlinkFlow 🚀

Welcome to the BlinkFlow repository! We are building a **1-Click Escrow Invoices for Web3 Freelancers & B2B** on Solana.
This project is built during the **Solana Colosseum Hackathon (Sep 14 - Oct 12, 2026)**.

## 💡 The Vision
Freelancers and B2B contractors lose 10% in fees and weeks in time waiting for SWIFT or fighting Upwork blocks. Crypto transfers lack trust (no escrow).
**BlinkFlow** solves this by packaging a non-custodial Escrow Smart Contract into a highly viral **Solana Action (Blink)**. 
Freelancers can drop an invoice directly into a Telegram chat or Twitter. The client clicks "Pay", funds are locked on-chain, and after the work is done, the client clicks "Release".

## 📁 Repository Structure
- `/solana-program` - Rust / Anchor smart contract.
- `/app` - Next.js frontend and API routes for Solana Actions.
- `/docs` - Documentation, architecture, and PRD.
